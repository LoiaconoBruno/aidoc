aidoc: estructura para IAs

Digerir una vez, usar muchas veces. Pegá una página web, un Markdown o un texto y obtené un paquete aidoc v0.1: texto canónico, secciones, tablas, enlaces, imágenes y fragmentos listos para buscar, cada uno con su huella. Y cuánto se ahorra en tokens.

Entrada

Validar un .aidoc

Revisa la forma y que cada fragmento coincida con el texto y con su huella.

Medición

Todavía nada
—

Tokens estimados con la regla gruesa de 1 token ≈ 4 caracteres: sirve para comparar, no para facturar.

Todo se procesa en tu navegador; nada se sube. Las imágenes se listan con su texto alternativo: describirlas (o leer su texto) queda para un paso con un modelo de visión.
